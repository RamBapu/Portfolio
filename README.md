# 📌 Project Overview

This portfolio website is designed to present my work, skills, and experience in a clean and interactive way.

It includes:

- 🎨 Beautiful and responsive UI
- ✨ Smooth animations using Framer Motion
- 📄 Resume integration
- 📧 Contact form with EmailJS
- 🔔 Toast notifications for user feedback
- 🧭 Clean navigation with modern navbar

# 🔍 Architecture Explanation

## 1️⃣ App Router Structure

- Built using Next.js App Router
- Organized into reusable sections
- Component-driven architecture

## 2️⃣ Component Design

- Modular and reusable components
- Separation of concerns for UI sections

## 3️⃣ Styling

- Tailwind CSS for utility-first styling
- `tailwind-merge` for conditional class handling

## 4️⃣ Animations Layer

- Framer Motion used for:
  - Page transitions
  - Section animations
  - Interactive UI elements
